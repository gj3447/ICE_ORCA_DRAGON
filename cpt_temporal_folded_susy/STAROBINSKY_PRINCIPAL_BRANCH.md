## Exact model and representation

Use the existing Euclidean Dirichlet-reduced action, with the same dimensionless
normalization as the seed certificate and midpoint audit:

```math
L_E=2\pi^2[-3a u^2+\tfrac12a^3v^2-3a+a^3V(\phi)],
\quad V=\tfrac34(1-e^{-\sqrt{2/3}\phi})^2,
\quad (u,v)=(a',\phi').
```

The full Euler–Lagrange flow is used, including its constraint-preserving
off-constraint extension. Its energy is
\(E=-6\pi^2aC\), with
\(C=u^2-1-a^2(v^2/2-V)/3\) and \(C'=-(u/a)C\).
The added state \(I'=L_E\), \(I(0)=0\), evaluates the on-shell action.
All integration uses normalized time \(s=\tau/T\).

For endpoint parameters \(b=(a_L,\phi_L,a_R,\phi_R)\), solve

```math
F(y;b)=(a(T)-a_R,\phi(T)-\phi_R,C_L)=0,
\qquad y=(u_L,v_L,T).
```

Each cell uses one fixed shooting box. CAPD encloses the full C1 flow over that
box and over the entire independent endpoint parameter box. A single exact
rational Krawczyk calculation encloses \(F(c;b)\) for all parameters and
\(D_yF\) for all shooting/parameter values. Strict inclusion and a weighted
defect norm below one establish existence and uniqueness within the declared

flow and the implicit function theorem. No interval sample grid substitutes for

\(p^+ = -\partial_{q_m}S_R\), and \(M=2\pi^2\mathrm{diag}(-6a,a^3)\).
