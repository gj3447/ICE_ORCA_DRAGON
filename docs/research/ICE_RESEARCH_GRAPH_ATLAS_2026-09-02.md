# ICE ORCA DRAGON research graph atlas

Date: 2026-09-02

Status: active navigation architecture; no scientific claim or execution authority

## Answer first

ICE ORCA DRAGON is one computational workbench with four independent evidence graphs, not one fused
theory graph. The authored source of truth is the native JSON collection and its registered graph JSON
files. Raw calculation results remain the check-ledger authority. Reading paths, GraphRAG, SPARQL,
JSON-LD/RDF, SHACL, PROV-O and RO-Crate are query, validation or interchange views over those records;
none of them promotes a result into physics.

Use the route-role view before entering a research lane:

```bash
./ice ontology guide --path cpt-role-bands-no-promotion
./ice ontology guide --path choice-invariance-cross-domain-audit
```

That view separates four operational roles:

| Route role | Meaning | What it may establish |
| --- | --- | --- |
| `TOE_CORE` | Ordered G1 through G5 candidate route | Only the named typed output of the current gate |
| `G1_SUBBLOCKER` | Source-cycle and joint-intersection obligations immediately inside G1 | A reviewed input to G1, never G1 closure by proximity |
| `SUPPORTING_P1`–`SUPPORTING_P7` | Operator, harmonic, algebra, BFV and observable methods | Scoped supporting results until an explicit core evidence edge changes |
| `HISTORICAL_NONEXECUTABLE` | Phase 51–56 reconciliation provenance and consumed Gate-1 one-shots | Audit history only; no rename, retry, descendant or execution route |

## Canonical content topology

The collection boundary is intentional:

| Graph | Scientific role | Current boundary |
| --- | --- | --- |
| `hypercomplex` | Exact finite algebra and proposed interpretation tests | Some finite structures survive; a physical referent is not established |
| `legacy` | User-primary narrative and historical numerical-prediction audits | Narrative is preserved, while the stored signal and independent-preregistration gates do not pass |
| `cpt` | Main CPT × temporal-folded SUSY calculation programme and TOE-candidate route | Scoped local, operator and harmonic facts exist; Gate 1 and every physics/empirical promotion remain open |
| `igrueqft` | Independent finite locality falsifier | One frozen free-U(1) shortcut is contradicted; interacting/continuum locality remains undecided |

These graphs may share a collection reading path, but they do not exchange evidence. A topical match,
resolved external UID or retrieval hit is not a derivation or corroboration.

Within a graph, author the smallest truthful chain:

```text
source ─CITES→ concept
concept ─MOTIVATES→ open_problem
claim ─VALID_WITHIN→ scope
claim ─HAS_EVIDENCE/(SUPPORTS|CONTRADICTS)→ evidence
evidence ─RECORDED_IN→ artifact
downstream open_problem ─BLOCKED_BY→ prerequisite open_problem
```

An analytic review, convention ledger or method-only control need not be inflated into a claim merely to
increase graph degree. Conversely, a numerical result is not evidence for a claim unless the graph names
the claim, polarity and scope. `PART_OF` supplies programme cohesion, not scientific entailment.

## CPT route architecture

### TOE core

The only core spine is:

```text
G1 original regulated joint cycle and signed global intersections
  → G2 hard CFU Airy/Airy-prime coefficients
  → G3 full BFV/Pfaffian/Pin holonomy
  → G4 spinorial charge/domain/constraint closure
  → G5 persistent ordering and pole splitting
  → external-review readiness criteria
```

The current blocker is G1. A complete zero intersection vector is an admissible negative resolution;
the graph does not require a positive signal. Read the compact handoff and the full gate spine with:

```bash
./ice ontology guide --graph cpt --path gate1-typed-object-handoff
./ice ontology guide --graph cpt --path toe-current-critical-path
```

G1 currently has two direct subblockers. One asks for an explicit finite-cutoff joint action, separately
specified admissible original cycles, complete saddle/sheet/singularity/Stokes/good-end census and
orientation-stable intersections. The other asks whether the retained local closed-FRW branch can be
promoted from a classical chart, principal endpoint FIO and local BFV zero-mode algebra to normalized
endpoint states, a spectral pairing, a trajectory source, zero lapse and a source-derived joint cycle.
Neither local signs nor a supporting Weyl calculation supplies the global integer vector.

### Choice-invariance boundary

No current result reaches broader model, physics, empirical, or TOE promotion. Such a widening would need
predeclared admissible choices, a mechanism-carrying typed object that persists across them, and at least
two independent in-graph consumers. Reuse of one residual or a match in another graph is not independent
evidence. In particular, G1 needs a deformation-stable global intersection vector (a stable zero is also
informative); P1 remains a scoped real-root handoff; P4 needs actual endpoint-to-m-to-measure-to-positive-RAQ
objects; P2–P5 need unprojected closure or a non-removable anomaly class; P6 needs an absolute gluing
measure; and P7 needs a normalized, choice-robust observable before likelihood. See the active
[choice-invariance promotion boundary](../decisions/ICE_CHOICE_INVARIANCE_CROSS_DOMAIN_PROMOTION_2026-09-02.md).

### Historical provenance

Phase 38–56 records explain why local continuation and backend reconciliation did not determine the
global cycle. Phase 11–50 runners stay frozen and hash-pinned for exact historical reproduction only;
Phase 51–56 and the consumed Gate-1 one-shots stay searchable but their execution route is killed. Long
reading paths are explanatory archives, not default task queues. New science, if any, is a clean,
committed, unnumbered and independently bounded question run only through `./ice run`.

## Full-stack graph surfaces

| Concern | Repository surface | Authority boundary |
| --- | --- | --- |
| Authoring | `ontology/collection.json` and registered `graph.json` files | Only authored graph records |
| Raw evidence | Result JSON plus command, environment and checks | Calculation ledger authority |
| Native validation | strict TypeScript/Effect decoders and `./ice ontology validate` | Schema, semantics, hashes and evidence polarity |
| Change review | `./ice ontology review --graph all --base HEAD` | Deterministic record diff; human judgment remains required |
| Retrieval | `./ice graphrag search`, versioned retrieval suite and diff | Locator quality, not answer truth |
| Competency checks | `./ice ontology competency --json` | Stable architecture questions over the generated RDF dataset |
| Query | bounded local SPARQL 1.1 | Read-only inspection; no remote dataset, service or update |
| Interchange | JSON-LD 1.1, RDF 1.1 named dataset and N-Quads | Generated one-way projection; never imported as a second truth |
| Shape validation | SHACL 1.0 Core | Export shape only; native scientific validation remains separate |
| Provenance/package | PROV-O and RO-Crate 1.3 | Export lineage and metadata package, not scientific evidence |
| Agent access | read-only MCP plus graph-aware planner/harness | Context and review only; no numerical execution or ontology writes |

The stable baseline remains RDF 1.1, JSON-LD 1.1, SHACL 1.0 and SPARQL 1.1. RDF 1.2 is currently a
W3C Candidate Recommendation Snapshot, while SHACL 1.2 and SPARQL 1.2 are Working Draft families, so
their draft-only features are not repository requirements. RO-Crate 1.3 is the current community
Recommendation for optional graph-export packages. See the
[standards decision](../decisions/ICE_STANDARD_GRAPH_ENGINEERING_2026-09-01.md) for the precise profile
and non-claims.

## Standard handoff

For a fresh session or reviewer:

```bash
./ice status --json
./ice ontology summary --json
./ice ontology guide --path cpt-role-bands-no-promotion
./ice ontology guide --path choice-invariance-cross-domain-audit
./ice ontology guide --graph cpt --path gate1-typed-object-handoff
./ice graphrag eval --limit 12 --json
./ice ontology competency --json
./ice agent eval --json
```

For an authored graph change:

```bash
./ice harness impact <registered-repository-path>
./ice ontology review --graph all --base HEAD
./ice graphrag diff --base HEAD --limit 12 --json
npm run graph:check
```

Passing these checks means that the repository structure, locators and declared semantic invariants are
intact. It does not mean that a physical theory, new phenomenon or TOE has been discovered.
