3. 결과가 기존 claim·report와 연결될 때는 어떤 계산, 어느 입력, 어떤 한계인지 함께 적는다.
4. 수치 부합을 물리적 결론으로 바꾸지 않는다. 반증 가능성·외부 근거는 별도 상태로 둔다.
