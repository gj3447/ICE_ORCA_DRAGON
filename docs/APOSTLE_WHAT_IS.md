# 무엇인가 — ICE ORCA DRAGON

이 공개 저장소는 수치·형식·연구 기록을 분리해 다루는 계산 워크벤치다. 공개 README와 작업 규칙이 말하듯, 계산상의 일치만으로 물리학적 해석을 확정하지 않는다. 연구 질문과 관측·가설·검증 기록은 서로 다른 상태로 남긴다.

공개 `research/`는 hypercomplex 보조 계산, legacy prediction 진단, 과거 보고, intuition의 비권위적 질문 지도, benchmark의 설계 비교, hash-audited sidecar를 구분한다([research/README](../research/README.md)). 이 분류는 각각의 산출물의 성격을 설명할 뿐, 물리 이론의 진위를 선언하지 않는다.

## 읽을 때의 경계

- 실행 가능한 항목은 공개 `ice list`·`ice info`·`ice run` 경계에서 찾는다([research/README](../research/README.md)).
- intuition은 출처 연결 질문 지도이며 실행 권한이나 정전 근거가 아니다([research/README](../research/README.md)).
- historical report와 현재 workbench 결과를 같은 증거 등급으로 합치지 않는다.

출발점은 [README](../README.md), 연구 항목은 [research/README](../research/README.md)다.
