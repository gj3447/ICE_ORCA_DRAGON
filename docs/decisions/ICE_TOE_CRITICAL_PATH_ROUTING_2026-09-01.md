# TOE-directed critical-path routing

Date: 2026-09-01

Status: active navigation policy

## Decision

The user-declared north star of the CPT x Temporal-Folded SUSY programme is to
construct, or decisively resolve or falsify, the declared candidate route toward
an evidence-backed theory of everything.  This objective is a routing target,
not an established physics claim.  A negative result closes only its proved
scope or this candidate route, never every possible TOE.  The repository remains
a computational workbench, and a numerical or formal match does not by itself
become physics evidence.

Work may be called **core TOE progress** only after a human reviewer can name:

1. one canonical open-problem node and its still-missing typed object;
2. one bounded, falsifiable output that would resolve or narrow that object;
3. an explicit dependency path from that object to the next programme gate and
   ultimately to the terminal review criteria below; and
4. the principal false-signal class and proportionate independent check.

If any item is absent, the work is labelled `SUPPORTING_METHOD`, `MAINTENANCE`,
`ARCHIVE`, or `STOP_OR_REFRAME`.  It is not counted as core progress merely
because it is mathematically interesting, novel to the repository, or adjacent
to an active topic.

## Current bottleneck and dependency spine

The current first unresolved claim dependency is:

```text

  -> G2 regular hard CFU Airy/Airy-prime coefficients
  -> G3 physical BFV/Pfaffian/Pin line
  -> G4 positive product/common domain/full anomaly-free constraint closure
  -> G5 persistent gauge-invariant order + interacting pole splitting
  -> full-theory and empirical terminal review
```

Consequently, the default core target is
`open:gate1-original-cycle-signed-global-intersections`.  An admissible G1 task
must directly reduce at least one missing object: a source-defined regulated
joint relative class; a complete saddle, sheet, singular/Stokes and good-end
census; oriented intersections; or stability under the declared homotopy,
gauge and regulator refinements.  A complete stable zero vector is a valid
negative resolution.

The arrows are claim prerequisites, not a ban on exploratory downstream work.
G2--G5 calculations performed before compatible upstream typed inputs exist are
`CONDITIONAL` or `SUPPORTING_METHOD`.  They cannot be reported as core TOE
progress.  P1--P7 are supporting by default, not independent success counters;
a P-lane task becomes a core-routing candidate only when human review identifies
the exact G1--G5 missing object and evidence edge that its output would change.
In particular, local root refinements, finite Weyl proxies,
selected-H-only RAQ, finite harmonic packets, toy BFV gluing, likelihood work,
historical Phase replay, numerology, other independent ontology graphs, and
graph tooling do not advance the core path unless a named missing typed object
and dependency edge are actually changed.

This policy promotes the dependency information preserved in
`ICE_ORDERED_FIVE_GATE_PROGRAMME_2026-08-20.md` into current navigation only.  It
does not reactivate numbered phases, one-shot receipts, automatic unlocks, or
the killed Ragnarok route.  The current scientific status remains the one in
`ICE_CURRENT_PHYSICS_DISCOVERY_GAP_MAP_2026-08-31.md`.

## Repository completion predicate

The repository may emit `TOE_CANDIDATE_READY_FOR_EXTERNAL_REVIEW` only if one
declared model scope has independent support for all of the following:

1. compatible typed outputs for G1--G5, including the joint cycle, regular
   uniform kernel, physical determinant/Pfaffian/Pin line, positive physical
   product and common domain, full anomaly-free constraints, and a persistent
   gauge-invariant interacting effect;
2. full 3+1-dimensional local modes and arbitrary-background constraint
   algebra;
3. a regulator-independent continuum limit or an explicit UV completion;
4. positive physical states with unitary and causal dynamics;
5. recovery of general relativity and quantum field theory, including the
   relevant Standard Model/low-energy limit;
6. normalized physical observables with convention-stable predictions and at
   least one discriminator against viable alternatives;
7. comparison with data under an explicit likelihood and independent
   reproducibility review.

Item 7 is an intentional repository-level empirical completion requirement that
is stronger than the observational-discriminator wording in the historical
five-gate map.  Before data exist, the narrower theoretical status may be
reported explicitly, but it is not the terminal repository label.

This is a workbench completion predicate, not permission to claim that a TOE has
been discovered.  Scientific acceptance remains external.  A rigorous no-go or
stable null may close this candidate route without satisfying the user's TOE
objective; in that event, the route stops and a replacement programme requires
an explicit human decision rather than automatic offspring.

## Anti-meandering review

Before designing a new core calculation, run a CPT-scoped graph retrieval and
produce a human-review checkpoint.  The reviewer must reject or reclassify a
proposal when any of these holds:

- it has no canonical blocker anchor or no explicit path to a terminal criterion;
- it changes coordinates, precision, backend, tolerance, or solver without
  testing a named scientific obstruction;
- it repeats a local lemma after the required scoped theorem is already present;
- it builds machinery with no named downstream consumer;
- it uses a downstream desired result to choose an upstream contour, domain,
  regulator, or state;
- it treats another independent ontology graph as corroboration without an
  explicit evidence-backed bridge; or
- it creates a successor task merely because the preceding bounded calculation
  finished.

`./ice agent plan` is a core-labelled navigation and handoff aid only.  It blocks
its own calculation-design path for downstream or supporting work; that does not
ban a separately reviewed bounded supporting calculation under the lean rules.
It cannot approve a core-progress label, mutate the graph, persist its checkpoint,
or authorize `./ice run`.  Human review and the lean
one-question/one-output/non-claim rules remain mandatory.
