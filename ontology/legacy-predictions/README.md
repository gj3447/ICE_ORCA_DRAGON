# Legacy prediction and narrative ontology

> This graph preserves the user-primary narrative, historical prediction files, and later falsification
> audits without merging their epistemic roles. A narrative source is not computational evidence, and a
> historical file called “preregistration” is not automatically proved to predate comparison.

## Three layers

```text
USER_PRIMARY NARRATIVE
    motivation, names, imagery, “all is hypergraph”
                 │  motivates; does not prove
                 ▼
HISTORICAL L2/L3 PREDICTION BELT
    mass ratios, L*, Koide, mp/mW, P01–P15, gravity candidates
                 │  checked by null and provenance controls
                 ▼
CURRENT WORKBENCH VERDICT
    scoped contradictions, null results, provenance limits, open tests
```

## Narrative provenance

The current `나는야_ice_orca_dragon.md` contains a list and “그냥 모든것은 하이퍼그래프”. ICED and
absolute-zero imagery occur in other MIND documents. Several later retreat/reframe phrases are
interpretations or conversation-derived prose rather than verbatim lines in that one file. The graph
therefore keeps:

- source-backed user-primary statements;
- later interpretive synthesis;
- computational claims;

as separate nodes joined by `MOTIVATES` or `CONTRASTS_WITH`, never by an invented evidence edge.

## Four reading paths

1. **Narrative without erasure** — primary packet → preserved motivation → workbench layer boundary.
2. **From attractive number to null gate** — derivation → target registry → Monte Carlo/look-elsewhere
   control → scoped contradiction.
3. **Why “preregistered” is historical metadata** — list hash → first Git commit → same-commit result →
   provenance limitation → genuine future preregistration problem.
4. **What remains open** — corrected assessor semantics, source-refresh observable tests, substantive
   Lean form-uniqueness proof, and precise quotation attribution.
